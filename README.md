# KidooFlow

Prototype V0.3 de validation produit.

- Web-app statique, mobile-first
- Mémoire locale via localStorage
- Pas de serveur ni compte utilisateur pour le moment
- Pas de service worker afin d'éviter les problèmes de cache pendant les tests
